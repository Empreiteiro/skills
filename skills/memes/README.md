# Meme skills

Skills for running a humor/meme page on Instagram (or TikTok, Shorts): writing posts in the page's own voice and
language, and rendering them — square text and chart posts, and vertical videos that end on the post.

```
meme-post/       text posts: the line on the image, the caption, the hashtag block; the page profile
  scripts/         card.py (renders the square post), analyze_posts.py (learns the voice from an archive)
  references/      page-template.md (the PAGE.md profile)
meme-chart/      posts where the drawing is the joke: zigzag line, staircase, bars, pie
meme-reel/       1080x1920 videos generated by code, ending on the still post
  scripts/         stage.py (frame, timing, encoder), example_reel.py
meme-game/       a series of reels told as a 1-bit platform game
  scripts/         pixel.py (engine + level 1-1)
  references/      shadow-style.md (silhouette-against-fog variant)
```

## Skills

| Skill | What it does |
|---|---|
| `meme-post` | Writes a post — the line on the image and the caption — in one of eight joke formats, picks the hashtag block, renders the PNG |
| `meme-chart` | Posts where the drawing is the joke; same renderer, four drawings |
| `meme-reel` | Writes or adjusts a scene: a video that animates the post's entrance and ends on it, still |
| `meme-game` | The platform-game series: world rules, sprites as text, the grammar of a level |

`meme-post` is the base: it owns the page profile and the renderer, and the other three use both.

## The page profile

Each page keeps a `PAGE.md` at its project root — name, handle, language, the condition it jokes about, voice,
hashtag blocks, look. `meme-post` builds it the first time, from the page's post archive when there is one
(`analyze_posts.py` reads a CSV or JSON export) or from a handful of its best posts. The other skills read it.

Skills are available as `/empreiteiro:meme-post`, `/empreiteiro:meme-reel`, and so on. Without the plugin system,
copy the four folders together to `~/.claude/skills/` or a project's `.claude/skills/`: the scripts import each other
through the sibling folders.

## Requirements for the scripts

- Python 3.9+ and `pip install pillow`
- For videos, an ffmpeg: on the PATH, or `pip install imageio-ffmpeg`
- A bold monospace font. Roboto Mono is used when installed; otherwise the system's (via `fc-match`). Set
  `MEME_FONT` or the spec's `font` to pick one.

## Where the guidance comes from

The voice rules and numbers were distilled from a 664-post archive of a Brazilian money-humor page (2020–2024,
1.29 million likes): what made captions draw comments, how long the lines were, which joke formats recurred, and
what each animation and drawing rule learned by getting it wrong. They are defaults; `analyze_posts.py` gives the
same numbers for your own page.
